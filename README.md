# Tugas Kloning Website - [Mediatek]

Repositori ini dibuat murni untuk memenuhi tugas mata pelajaran.

## Deskripsi

Proyek ini adalah hasil kloning tampilan (UI) dari website (Mediatek) yang digunakan sebagai media pembelajaran pemrograman web.

**Catatan Penting:**
Repositori ini tidak mengandung fungsionalitas backend, tidak mengumpulkan data pengguna, dan tidak terafiliasi dengan website resmi terkait. Proyek ini tidak digunakan untuk tujuan komersial, ilegal, atau phishing.
